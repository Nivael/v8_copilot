# #2 — P6B 重整前偿债压力与市场重定价地图

PRD：[V8_P6B_PRD.md](../V8_P6B_PRD.md)

**Problem:** 典型重整候选可能资不抵债、无法使用收益法且存在隐性负债。强行计算传统
价值区间会把缺口包装成精确数字；只展示同日市值排名又只说明规模，无法说明进入困境后
市场如何重定价。

**Expected behavior:** 不使用未来方案事实，分别输出资产/偿债地图和同口径市场定价地图。
同日 ST 分位只描述规模；episode 相对重定价描述进入本轮 ST 后相对 ST 组合的价格路径。
证据不足时返回 unknown，v1 不输出低估、底部、目标价或交易信号。

## Frozen rules

- [x] 同日市值使用交易日整市场 `daily_basic` 截面并按历史 membership 过滤。
- [x] 有效样本少于 20 家或市值覆盖率低于 95% 不出分位。
- [x] v1 不用陈旧市值补 cohort 覆盖；5 日规则只保留为未来资本结构 guard 完成后的
  可晋级路径。
- [x] 同日分位固定标注 size position；低尾不等于便宜，高尾不等于昂贵。
- [x] 自身历史只显示固定 12 个月变化、成员数和 Jaccard cohort 换手。
- [x] episode 相对重定价使用个股 qfq / 排除目标的 ST 等权财富指数比，不用市值变化减价格指数。
- [x] 2021-03-17 前 ST 等权不可用时返回 gap，不拿其他基准替代。
- [x] 股本变化但缺精确老股东权益账时标记 `capital_structure_contaminated`。
- [ ] 同阶段分布至少 20 episode / 15 公司；门槛只许上调、不许下调。
- [ ] 阶段标签必须 100% 来自核证后的 `valuation_episode_v1`。
- [ ] 资产状态为 `unknown` 时市场定价残差必须 `not_calculable`。
- [ ] v1 不启用收益法，不做资产价值加壳价值，不发布估值偏离标签。

## P6B-0 — dry plan

- [x] 以逐日 `st_membership_daily` 只读构造连续候选 valuation episode；
  `st_status_history` 只作来源交叉核查。
- [x] 列出唯一锚点交易日和按交易日整市场请求量，不按 symbol × date 估算。
- [x] 按年代报告目标/成员价格缺口代理和 0/5/20 日陈旧覆盖。
- [x] 报告 95% market-cap 覆盖门的历史边界；无法冻结时明确停止。
- [x] 盘点股本跳变、退市终点和 M6 候选阶段覆盖；P6A 尚无材料化数据，不冒充输入。
- [x] 生成小规模 read-only provider probe 计划；dry plan 本身不联网、不写生产库。
- [x] 输出人类只需确认的一页规则摘要。

**Exit:** 历史边界、请求量、停牌规则和 source probe 范围冻结。不可行时缩小范围，不进入
P6B-1。

**2026-07-24 结果：** `P6B0-BE1B382B7CF794EBAECA` 在 2026-07-20 截止数据上得到
1,118 轮候选 episode / 782 只股票 / 209 轮开放状态；306 个唯一入场锚点日，因此历史
`daily_basic` 请求按 date-only 计算为 306 次。逐日 membership 相对完整交易日历缺 25 日，
9 轮边界邻近空洞；196 轮命中 M6 重整候选，但 M6 的 8,009 条记录仍全部是
`case_note_only`。本地仅有 1 个 market-factor snapshot、0 个精确资本结构 adjuster，
qfq 价格代理也没有连续通过 95% 门，因此可发布市场地图的历史起点尚未冻结。

P6B-0 的后续 probe 已完成：`P6BP-574C9D1EEA97E0DF953B` 证明 11/11 个冻结日期均有
历史整市场返回，匹配成员的 `total_share` / `total_mv` 字段完整；3/3 个资本结构样本也有
连续历史股本并检出实际跳变。因此 P6B-1 可以从 2016-08-09 开始做 306 日期 scoped
backfill。

但只有 3/11 个冻结截面通过 95% cohort 覆盖门，失败日期跨年份非单调。安全默认已自动
冻结：不声称存在单一连续发布边界；每个锚点日独立过门；v1 不用陈旧市值补覆盖；老股东
稀释仍由 P6B-2 处理。详见
[P6B0_PROVIDER_PROBE_RESULT.md](../P6B0_PROVIDER_PROBE_RESULT.md)。owner 无需逐公司或
逐日期审核。

## P6B-2 — 资产与老股东权益 pilot

- [ ] 选择 5–10 家资产结构、程序结果和退市状态不同的公司。
- [ ] 材料化 point-in-time 财务、重述、担保、诉讼、资金占用和处置事实。
- [ ] 输出 adjusted net assets 的 `positive` / `negative` / `unknown` 三态。
- [ ] 输出 equity asset backing、solvency gap 和缺失负债敏感度。
- [ ] 建立每股稀释、股份归属、受让对价和老股东保留权益最小账。
- [ ] 若超过一半 pilot 无法精确闭环，冻结全量范围输出主口径。
- [ ] 折价率无独立校准样本时保持逐项列示和 `uncalibrated`。

**Exit:** 人类只处理不超过 10 个 decision cluster；超过 review budget 则改规则、缩范围或
保持 unknown。

## P6B-3 — 核证 valuation episode

- [ ] 定义连续 ST 区间、重复 ST、失败后继续和 P6B/P6C 边界。
- [ ] 复用 M6/P6A 词表和来源索引，不自动晋级 `case_note_only`。
- [ ] 以 cluster 决策核证阶段；决定独立、幂等且不覆盖原始事实。
- [ ] 对 3–5 个代表例和 1–2 个反例完成批次验收，不逐条审核 270 条。

**Exit:** 用于统计的阶段标签 100% 为核证事实。

## P6B-4 — 同阶段描述与 shadow validation

- [ ] 门槛满足后输出阶段样本数、公司数、年份和描述性分布。
- [ ] 输入冻结在估值日，方案披露/失败/摘帽/退市保留为结果标签。
- [ ] 12 个月主窗口、6/24 个月辅助窗口分开记录。
- [ ] 退市同时报告 -100% 压力情景和最后交易所可观察代理。
- [ ] 历史回放与上线后前瞻样本分开；按公司聚类。
- [ ] 验证状态允许长期保持 `unvalidated`。

**Exit:** v1 仍不产生“估值偏离”或交易标签；任何晋级需未来独立 PR。
