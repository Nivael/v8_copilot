# #4 — P7 每日公告、异常量价与研究优先级

PRD：[V8_P7_DAILY_INTELLIGENCE_PRD.md](../V8_P7_DAILY_INTELLIGENCE_PRD.md)

P7-0 契约：[V8_P7_0_DRY_PLAN_CONTRACT.md](../V8_P7_0_DRY_PLAN_CONTRACT.md)

**Problem:** 当前公告可检索、价格可刷新，但没有连续自由流通换手/停复牌/一字板事实，
也没有发行人状态机和预注册 shadow ledger。用户仍需手工从每日大量公告和量价变化中挑出
值得先研究的标的。

**Expected behavior:** 每日自动整理正式公告、识别硬状态跃迁、标出相对自身历史的异常交易
活跃，并连接成可解释的研究队列。所有能力保留来源、覆盖和 unknown；研究优先级不等于买入
信号，v1 不输出资金流入或交易建议。

## Frozen rules

- [x] 公告和量价两个事实流独立计算，连接层不得回写原始事实。
- [x] 研究优先级不等于买入、卖出、持有或仓位建议。
- [x] 不使用“资金流入”“主力埋伏”等无法由日线证明的词。
- [x] P7B/P7C shadow 先于发布；P7A 可独立验收。
- [x] C14 复用不重做；连续活动进入独立 `market_activity_v1`。
- [x] 主换手口径固定为 `turnover_rate_f`；普通换手和 `volume_ratio` 仅作旁证。
- [x] 自身历史使用 120 个此前合格交易日、最少 60 个观察、median/MAD 与平均秩分位。
- [x] 默认 shadow profile 是 97.5% 分位且 robust z ≥ 4；MAD 为零不塞极小分母。
- [x] `daily_basic` 显式请求 `limit_status`；一字板编码 3/6，`stk_limit` 负责精确复核。
- [x] 停牌、一字板、退市整理期和不可判定状态不进入默认异常。
- [x] 复牌恢复期冻结为其后 5 个股票观察日：不生成默认异常，也不进入后续历史基线。
- [x] `volume_ratio` 不进入主异常判定。
- [x] 硬节点只认状态跃迁；一般进展公告不是 P7D 成功结果。
- [x] `stk_shock`、`stk_high_shock`、`stk_alert` 只作交易所公开参考；无权限不阻塞。
- [x] 阈值选择不得读取未来硬节点、交易所标签或收益。
- [x] Top-N 只限制展示，不删除 canonical 异常或 overflow。
- [x] owner 不逐公告、逐股票或逐日审核。
